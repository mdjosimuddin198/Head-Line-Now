# 📰 News Website

This is a modern and responsive news website built using JavaScript (React.js) CSS3 / Tailwind CSS / DaisyUi , HTML5 . It features multiple news categories, dynamic content loading, and a clean UI design suitable for blogs, news portals, or magazine-style platforms.

## 🚀 Features

- Responsive design for mobile and desktop
- Category-based news sections
- Modern UI/UX
- Easily customizable codebase

## 📁 Technologies Used

- HTML5
- CSS3 / Tailwind CSS / DaisyUi
- JavaScript (React.js)
